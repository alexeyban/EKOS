# EKOS Pioneer Program

We're looking for **10 pioneers** to be the first real-world users of EKOS outside the
core team. In exchange for hands-on testing and honest feedback, pioneers earn $EKOS
tokens — paid per task, not all-or-nothing.

## How it works

1. **Claim a spot.** Fill out the [signup form](https://docs.google.com/forms/d/e/1FAIpQLSftAJM-I7XzAx7HaT0YlBX8RGEclRYF7GoKpJeSUWin5-l_6Q/viewform). Spots are first-come,
   first-served — once 10 are confirmed, the program is closed to new signups.
2. **Do any of the 5 tasks below, in any order.** They're independent — you don't need
   to finish all 5 to get paid for the ones you do.
3. **Submit proof.** Reply to your confirmation email or the [pinned GitHub Discussion
   thread](https://github.com/alexeyban/EKOS/discussions/4) with a link/screenshot for
   each completed task.
4. **Get verified and paid.** We check each submission (manually, with AI-assisted
   review) and pay out that task's tokens to your wallet within a few days — no need to
   wait for the others. Payment processing is done manually, and is completed within
   **2 days of manual verification** of each submitted task.

## Tasks and rewards

| # | Task | Reward | What counts |
|---|---|---|---|
| 1 | Share on LinkedIn or X | **150,000 $EKOS** | A public post about EKOS — what it is, why it's interesting to you. Tag/link the repo. Low-effort reposts without commentary don't qualify. |
| 2 | Propose a use case | **125,000 $EKOS** | A written description of how you'd (or your org would) use EKOS — a real scenario, not a generic pitch back at us. A few paragraphs is plenty. |
| 3 | Test the product | **100,000 $EKOS** | Actually run EKOS against a real workspace — the CLI pipeline (`init → build → recover → resolve → compile → commit`) or `ekos mcp serve` — and tell us what happened. |
| 4 | Write a review | **100,000 $EKOS** | A public, honest review (blog post, X/LinkedIn long-form, or a GitHub Discussion post) of your experience. Critical feedback is welcome and doesn't disqualify you. |
| 5 | ⭐ Star the GitHub repo | **25,000 $EKOS** | Star the repo. That's it. |

**Total available per pioneer: 500,000 $EKOS** (~$6.50 at current internal valuation).
**Total program pool: 5,000,000 $EKOS**, capped at 10 pioneers.

## Rules

- One spot per person. No duplicate/alt-account submissions.
- Submissions must be genuine and public (we need to be able to verify them).
- We reserve the right to reject low-effort or spammy submissions (e.g. a one-word
  tweet, a copy-pasted review) without payment.
- Bugs found while testing are welcome as GitHub issues — this isn't a paid task on its
  own, but it helps your review/use-case carry more weight during verification.
- Payment is in $EKOS tokens; you're responsible for having a wallet able to receive them.

## Data & consent

To run this program we collect your name, email, GitHub/social handles, and (from
confirmed pioneers only) a wallet address to pay out $EKOS. This data is used solely to
verify task submissions and pay rewards — it won't be sold or used for marketing without
separate consent. Contact the maintainers to request deletion of your data after the
program ends.

By signing up, you'll be asked to separately confirm:
- Agreement to the program terms above (spots, tasks, verification, rejection criteria).
- Consent to EKOS collecting and processing the personal data you submit, for the
  purpose of running the Pioneer Program, as described above.

## Why we're doing this

EKOS is a compiler for enterprise knowledge, not a database or document store — it only
gets better with real usage against real enterprise systems. The Pioneer Program is how
we get our first outside signal: does this hold up outside the environment it was built
in? Pioneers who go deep get compensated for the time that takes.

Questions? Open a GitHub Discussion or reach out to the maintainers directly.
