§ 06 / honest limits
What this deck won't overclaim

Two real, disclosed gaps — not smoothed over.

  • No ADF connector yetReal pipeline/dataset/linkedService JSON in adf-pipelines is captured as plain files, not parsed into pipeline/activity objects — RFC 0038 Phase 5, not yet built.
  • API.md predates the new analyzersThe curated API.md page still uses a legacy heuristic text-scan for symbol names, not the richer RustSymbol/PythonSymbol KIR objects RFC 0040/0041 added — a known follow-up, not fixed in this pass.
