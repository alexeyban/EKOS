§ 06 / honest limits
What this deck won't overclaim

Real, disclosed gaps — not smoothed over.

  • No ADF connector yetReal pipeline/dataset/linkedService JSON in adf-pipelines is captured as plain files, not parsed into pipeline/activity objects — RFC 0038 Phase 5, not yet built.
  • Redaction is a fixed pattern table, not a guaranteeRFC 0043's built-in secrets/PII baseline (AWS/GitHub/Slack/Google/Stripe token shapes, PEM keys, JWTs, generic key/password assignments) runs on every one of these three doc-generation passes automatically — but it's a known, transparent list, not statistical/entropy-based detection. A secret shaped like none of those patterns won't be caught. Stated as a limit, not hidden.

The previous gap this deck disclosed here — API.md using a legacy text-scan instead of real RustSymbol/PythonSymbol objects — is fixed as of RFC 0042: every API.md above now links real program entities, not scanned identifier strings.
