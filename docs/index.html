EKOS lives at ekos.dev

EKOS is the open-source knowledge layer for AI agents: it compiles code, SQL, documentation and Git history into evidence-backed knowledge that agents query over MCP. The project site, documentation and quickstart are at ekos.dev.

Go to ekos.dev →

This GitHub Pages site keeps two things:

  • Capabilities reference Every capability, CLI command and MCP tool, kept current with each release.
  • Presentations Live, unedited runs against real repositories, benchmarks and case studies.
  • Install EKOS The setup wizard for Linux, Windows 11 and macOS, or the command alone.
  • Source on GitHub RFCs, devlogs and the Rust workspace.
