44 crates with no declared version
Every internal crate in the workspace uses version.workspace = true rather than a literal per-crate version string — the analyzer reads the literal field, so it (correctly) reports "not declared" rather than resolving the workspace-inherited value. A real analyzer limitation, not a real versioning problem.

Every module-level item in the workspace, undocumented at the module level (function/struct-level docs are a separate, better-covered count below). RFC 0087's doc-comment capture has nothing to show for any of them.
